# Seyi Airways Website

A responsive multi-page airline website built as a university /  personal project. I designed, wrote and styled every page myself.

**Live site:** https://oluwaseyiadegbite.github.io/MY-AIRWAYS-WEBSITE/

### Pages and features
- Homepage with a navigation menu (Discover, Book, Help, Manage) and a "Find Your Perfect Flight" search panel with trip type, travel class and passenger options
- Best offers and destination promo sections
- About, Experience, Travel Classes, What's New and On Business pages
- Contact / Help page and Manage booking page
- Travel guidance and vouchers pages
- Privacy policy page

## Built with
- HTML
- CSS


### What I learned
- Structuring a multi-page website with a shared navigation and footer
- Building a responsive layout that works on phones, tablets and computers
- Styling pages professionally with CSS
